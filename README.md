# 暖词 · Windows 取词翻译助手

> 一个离线优先的 Windows 桌面取词工具：鼠标悬停取词、划词翻译、快捷查词、生词本。
> 词库用本机的 MDict（`.mdx`）文件或开源的 ECDICT，取词用屏幕文字识别，不依赖任何商业词典程序。

一个用 Python 写的轻量取词翻译工具，替代欧路词典那类商业软件的常用功能：

- 鼠标悬停自动取词，浮窗显示释义（网页 / PDF / 图片 / 游戏里的英文都能取）；也可以设成「按住 Ctrl/Shift/Alt 才取词」
- 划词翻译整句，并列出句中生词（常用词自动略过，生词本里的词标星）
- 全局快捷键查词，支持补全（↑↓ 选择）、词形回溯（happily→happy、bigger→big）与拼写纠错（dictionery→dictionary）
- 生词本收藏 / 导出 CSV / 导出 Anki
- 英式 / 美式真人发音
- 托盘常驻，开机自启；操作没成功时托盘气泡会告诉你原因

## 功能一览

| 功能 | 说明 |
|---|---|
| 鼠标自动取词 | 鼠标停在屏幕上任意英文单词约 0.6 秒，浮窗显示词典释义；移开约 1 秒后收起，可「钉住」常驻。设置里可改成「按住 Ctrl / Shift / Alt 才取词」，读文章时不会乱弹 |
| 手动取词 | `Ctrl+Alt+E` 立即取鼠标下的词（查不到也会弹窗说明） |
| 快捷查词 | `Ctrl+Alt+D` 打开查词窗，弹出即可打字；输入即查，补全可用 ↑↓ 选，查不到时给出「你要找的是不是」 |
| 翻译选中内容 | 选中文字后 `Ctrl+Alt+T`，英文→中文（或中文→英文）整句翻译 + 句中生词列表；读选区不会弄丢你原来的剪贴板 |
| 生词本 | 浮窗/查词窗「收藏」按钮或 `Ctrl+Alt+B`；托盘菜单打开生词本，支持导出 CSV 和 Anki |
| 发音 | 浮窗与查词窗的「英」「美」按钮，调用在线发音并本地缓存 |
| 多词典 | 同时加载多本 `.mdx` 词典和 ECDICT，按顺序合并显示；自动解析 MDict 的 `@@@LINK` 跳转 |
| 开机自启 | 默认开启，托盘菜单或设置里可关 |
| 设置界面 | 托盘右键「设置」：快捷键改键、词典增删排序与一键下载 ECDICT、取词方式、翻译发音、开机自启，保存即生效 |

## 界面风格

暖米白纸面 + 焦糖色点缀 + 楷体标题，几套窗口统一风格：
- **取词浮窗**：贴鼠标的圆角小卡，词性/编号做成小标签，中文释义单独着色
- **查词窗**：居中大窗，输入框 + 补全下拉 + 多词典释义
- **生词本**：列表 + 发音 / 删除 / 导出

## 系统要求

- Windows 10 / 11（推荐 Win11，使用系统 WebView2 渲染界面，Win11 自带）
- 从源码运行需要 Python 3.10+（64 位）；用打包版不需要

## 快速开始

### 方式一：下载打包好的版本（推荐）

到 [Releases](../../releases) 下载 `WarmWord-windows.zip`，解压后双击 `WarmWord.exe`，不用装 Python。

### 方式二：从源码运行

1. 安装 [Python 3.10+](https://www.python.org/downloads/)（64 位，安装时勾选 *Add Python to PATH*）
2. 双击 `启动.bat` —— 首次运行会自动建虚拟环境并安装依赖（需联网，自动使用清华镜像）

### 第一次启动

托盘出现「词」字图标即启动完成。还没配词典时会自动打开设置窗口，二选一：

- 点「**下载开源词库 ECDICT**」：约 63MB，77 万词条，带音标、考纲标签和词频，下载完自动启用
- 点「**添加词典文件**」选你自己的 `.mdx`

## 词典怎么来

- **ECDICT**（[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可）：设置里一键下载；GitHub 连不上时可以手动下载 `ecdict.csv`，再用「添加词典文件」选它。第一次加载会花半分钟左右建索引，之后秒开
- **MDict 格式（`.mdx`）**：跟欧路词典、GoldenDict 用的是同一种格式
  - [MDict 词库资源区](https://www.pdawiki.com/forum/forum.php)（各种开源/自制词库）
  - 你已在欧路词典里导入过的词库，一般位于 `%APPDATA%\Francochinois\eudic\` 目录

> 本项目不附带任何词典文件（商业词典有版权，请自行合法获取）。

## 快捷键

托盘图标右键第一项就是**设置**，快捷键点一下键位、直接按新组合键，保存即生效。被别的软件占用的快捷键会弹气泡提示，设置里显示红点。

| 快捷键 | 作用 |
|---|---|
| 鼠标悬停 0.6 秒 | 自动取词（可关，或改成按住某键才取） |
| `Ctrl+Alt+E` | 取鼠标下的词 |
| `Ctrl+Alt+D` | 快捷查词窗 |
| `Ctrl+Alt+T` | 翻译选中内容 |
| `Ctrl+Alt+B` | 把当前词收进生词本 |
| `Ctrl+Alt+S` | 开 / 关鼠标自动取词 |
| `Ctrl+Alt+Q` | 退出程序 |
| `Esc` | 关闭查词窗 / 翻译窗 / 生词本 / 设置 |

> 旧版本默认的 `Ctrl+Alt+A`（QQ 截图）和 `Ctrl+Shift+A`（钉钉截图、Chrome 搜索标签页）容易冲突，新版默认改成了上表的键位。已有配置的用户键位不变，如有冲突在设置里改即可。

托盘菜单还有：生词本、开机自启开关、自检报告、重启程序、退出。

## 整句翻译

几个翻译来源同时请求，按优先级取第一个成功的结果，连不上的来源之后 10 分钟内不再等它：

1. **百度翻译开放平台**（选填）：在 [fanyi-api.baidu.com](https://fanyi-api.baidu.com/) 免费申请 APP ID 和密钥，填进设置。国内网络推荐
2. 谷歌免费端点（无需密钥；国内网络通常连不上）
3. MyMemory 免费接口（无需密钥，每日有额度）

翻译窗底部会显示这次用的是哪个来源。

## 数据存放位置

配置、生词本、发音缓存、导出文件、日志都放在 `%APPDATA%\WarmWord`（设置窗口里有「打开」按钮）。
旧版本放在程序目录里的 `config.json` 和 `生词本.json` 会在首次启动新版时自动复制过去。

想做成便携版（数据跟着程序走）：在程序目录放一个空的 `portable.txt`。

## 配置项（config.json）

| 字段 | 默认 | 说明 |
|---|---|---|
| `dictionaries` | 空 | 词典列表（路径 + 显示名），支持 `.mdx` / ECDICT 的 `.csv` / `.db` |
| `hotkeys` | 见上表 | 快捷键，格式 `ctrl+alt+d` |
| `auto_capture` | `true` | 启动时是否开启鼠标自动取词 |
| `capture_modifier` | `""` | 空 = 停住就取词；`ctrl` / `shift` / `alt` = 按住该键才取词 |
| `capture_only_english` | `true` | 取词只认英文（中文不弹窗） |
| `hover_delay_ms` | `600` | 悬停多少毫秒触发取词 |
| `online_translate` | `true` | 整句翻译是否联网（关掉只用本地词典） |
| `baidu_appid` / `baidu_key` | 空 | 百度翻译开放平台的 APP ID 和密钥 |
| `autostart` | `true` | 是否开机自启 |
| `debug` | `false` | 开启调试用的触发文件（`触发.txt`） |

## 工作原理

- **词典**：`mdict-utils` 直接解析 `.mdx`，内存建索引，查询毫秒级；ECDICT 转成 sqlite 索引后按需查询。自动处理 MDict 的链接跳转、词形回退、前缀补全与编辑距离纠错。
- **取词**：Windows 文字接口在浏览器等程序里取不到文字，因此主用「屏幕识别」——截取鼠标周围一小块屏幕（约 600×90 像素），用 RapidOCR（PP-OCR 模型）识别，再按字符宽度定位鼠标下的词。单次约 0.3 秒，支持多显示器。
- **界面**：pywebview + WebView2，五个页面用 HTML/CSS 写；浮窗常驻屏幕外保活，页面每 120 毫秒回调 Python 执行取词（文字接口只能在主线程用，界面线程又被界面库占着，取词因此放在独立小进程里，请求带编号防止结果错位）。
- **翻译**：见上文「整句翻译」。
- **发音**：有道发音接口 + 系统 MCI 播放 mp3，本地缓存。

## 已知限制

- 取词依赖屏幕识别，鼠标要落在文字上；识别约 0.3 秒，加上悬停延时总共约 1 秒出释义（「按住 Ctrl 取词」模式下更快）
- 词库原始 HTML 的复杂排版（多栏、图标）会被简化成单列文本，只保留词性、音标、中文、例句的层次
- 谷歌和 MyMemory 是免费接口，可能变动或限额；需要稳定翻译请配置百度翻译
- 仅 Windows（依赖 Windows 的文字接口 / 屏幕截取 / MCI）

## 目录结构

```
app.py                主程序（窗口、热键、托盘、取词调度）
paths.py              程序目录 / 数据目录约定
dict_engine.py        词典引擎（mdx / ECDICT 解析、查询、纠错）
wordlist.py           整句翻译里挑生词（常用词表）
screen_ocr.py         屏幕文字识别取词
capture_service.py    取词服务（独立进程，识别 + 文字接口）
capture_client.py     取词服务客户端（管道通信）
text_capture.py       Windows 文字接口取词（选区、取词、剪贴板）
translate.py          整句翻译（多来源并发）
ui/                   五个界面页面（浮窗 / 查词 / 翻译 / 生词本 / 设置）
tests/                单元测试与打包冒烟测试
config.example.json   配置模板
启动.bat               一键启动（首次自动建环境）
```
