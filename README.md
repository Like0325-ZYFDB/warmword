# 暖词 · Windows 取词翻译助手

> 一个离线优先的 Windows 桌面取词工具：鼠标悬停取词、划词翻译、快捷查词、生词本。
> 词库用本机的 MDict（`.mdx`）文件，取词用屏幕文字识别，不依赖任何商业词典程序。

一个用 Python 写的轻量取词翻译工具，替代欧路词典那类商业软件的常用功能：

- 鼠标悬停自动取词，浮窗显示释义（网页 / PDF / 图片 / 游戏里的英文都能取）
- 划词翻译整句，并列出句中生词
- 全局快捷键查词，支持词形回溯与拼写纠错
- 生词本收藏 / 导出 CSV
- 英式 / 美式真人发音
- 托盘常驻，开机自启，托盘图标一键唤起

## 功能一览

| 功能 | 说明 |
|---|---|
| 鼠标自动取词 | 鼠标停在屏幕上任意英文单词约 0.6 秒，浮窗显示词典释义；移开后约 4 秒收起，可「钉住」常驻 |
| 手动取词 | `Ctrl+Alt+A` 立即取鼠标下的词 |
| 快捷查词 | `Ctrl+Alt+D` 打开查词窗，输入即查，带补全、词形回溯（tests→test）、拼写纠错（dictionery→dictionary） |
| 翻译选中内容 | 选中文字后 `Ctrl+Alt+T`，英文→中文（或中文→英文）整句翻译 + 句中生词列表 |
| 生词本 | 浮窗/查词窗「收藏」按钮或 `Ctrl+Shift+A`；托盘菜单打开生词本，支持导出 CSV |
| 发音 | 浮窗与查词窗的「英」「美」按钮，调用在线发音并本地缓存 |
| 多词典 | 同时加载多本 `.mdx` 词典，按顺序合并显示；自动解析 MDict 的 `@@@LINK` 跳转 |
| 开机自启 | 默认开启，托盘菜单可关 |
| 设置界面 | 托盘右键「设置」：快捷键改键、词典增删排序、取词习惯、翻译发音、开机自启，保存即生效（快捷键实时重注册、词典后台重载） |

## 界面风格

暖米白纸面 + 焦糖色点缀 + 楷体标题，三套窗口统一风格：
- **取词浮窗**：贴鼠标的圆角小卡，词性/编号做成小标签，中文释义单独着色
- **查词窗**：居中大窗，输入框 + 补全下拉 + 多词典释义
- **生词本**：列表 + 发音 / 删除 / 导出

## 系统要求

- Windows 10 / 11（推荐 Win11，使用系统 WebView2 渲染界面，Win11 自带）
- Python 3.10+（64 位）
- 至少一本 `.mdx` 格式的词典（见下文「词典」）

## 快速开始

1. 安装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 *Add Python to PATH*）
2. 双击 `启动.bat` —— 首次运行会自动建虚拟环境并安装依赖（需联网，自动使用清华镜像）
3. 把词典路径填进 `config.json`（或先复制 `config.example.json` 改名），重启程序
4. 托盘出现「词」字图标即启动完成

## 词典怎么来

本程序读取 **MDict 格式（`.mdx`）** 的离线词典，跟欧路词典、GoldenDict 用的是同一种格式。常见来源：

- [MDict 词库资源区](https://www.pdawiki.com/forum/forum.php)（各种开源/自制词库）
- 你已在欧路词典里导入过的词库，一般位于 `%APPDATA%\Francochinois\eudic\` 目录

> 本项目不附带任何词典文件（词典有版权，请自行合法获取）。

配置示例（`config.json`）：

```json
"dictionaries": [
  { "path": "C:\\词典\\oaldpe.mdx", "name": "牛津高阶" },
  { "path": "C:\\词典\\麦克米伦高阶英汉双解.mdx", "name": "麦克米伦英汉双解" },
  { "path": "C:\\词典\\oaldZhEn.mdx", "name": "牛津汉英" }
]
```

## 使用说明

托盘图标右键第一项就是**设置**：快捷键（点键位后直接按新组合键，保存即生效）、词典（添加/删除/排序，显示每本条目数）、取词习惯（自动取词、只取英文、悬停延时）、翻译与发音（联网开关、默认口音）、开机自启与隐藏托盘图标。

| 快捷键 | 作用 |
|---|---|
| 鼠标悬停 0.6 秒 | 自动取词（可关） |
| `Ctrl+Alt+A` | 取鼠标下的词 |
| `Ctrl+Alt+D` | 快捷查词窗 |
| `Ctrl+Alt+T` | 翻译选中内容 |
| `Ctrl+Shift+A` | 把当前词收进生词本 |
| `Ctrl+Alt+S` | 开 / 关鼠标自动取词 |
| `Esc` | 关闭查词窗 / 翻译窗 / 生词本 |

托盘菜单还有：生词本、开机自启开关、自检报告、退出。

## 配置项（config.json）

| 字段 | 默认 | 说明 |
|---|---|---|
| `dictionaries` | 空 | 词典列表（路径 + 显示名） |
| `hotkeys` | 见上表 | 快捷键，格式 `ctrl+alt+d` |
| `auto_capture` | `true` | 启动时是否开启鼠标自动取词 |
| `capture_only_english` | `true` | 取词只认英文（中文不弹窗） |
| `hover_delay_ms` | `600` | 悬停多少毫秒触发取词 |
| `online_translate` | `true` | 整句翻译是否联网（关掉只用本地词典） |
| `autostart` | `true` | 是否开机自启 |

## 工作原理

- **词典**：`mdict-utils` 直接解析 `.mdx`，内存建索引，查询毫秒级；自动处理 MDict 的链接跳转、词形回退、前缀补全与编辑距离纠错。
- **取词**：Windows 文字接口在浏览器等程序里取不到文字，因此主用「屏幕识别」——截取鼠标周围一小块屏幕（约 320×90），用 RapidOCR（PP-OCR 模型）识别，再按字符宽度定位鼠标下的词。单次约 0.3 秒。
- **界面**：pywebview + WebView2，三套页面用 HTML/CSS 写；浮窗常驻屏幕外保活，页面每 120 毫秒回调 Python 执行取词（文字接口只能在主线程用，界面线程又被界面库占着，取词因此放在独立小进程里）。
- **翻译**：免费翻译接口双源降级（Google 免费端点 → MyMemory），无需密钥；失败时只显示词典释义。
- **发音**：有道发音接口 + 系统 MCI 播放 mp3，本地缓存。

## 已知限制

- 取词依赖屏幕识别，鼠标要落在文字上；识别约 0.3 秒，加上悬停延时总共约 1 秒出释义
- 词库原始 HTML 的复杂排版（多栏、图标）会被简化成单列文本，只保留词性、音标、中文、例句的层次
- 整句翻译依赖免费接口，接口变动时需要调整 `translate.py`
- 仅 Windows（依赖 Windows 的文字接口 / 屏幕截取 / MCI）

## 目录结构

```
app.py                主程序（窗口、热键、托盘、取词调度）
dict_engine.py        词典引擎（mdx 解析、查询、纠错）
screen_ocr.py         屏幕文字识别取词
capture_service.py    取词服务（独立进程，识别 + 文字接口）
capture_client.py     取词服务客户端（管道通信）
text_capture.py       Windows 文字接口取词（选区、取词）
translate.py          整句翻译（免费接口双源）
ui/                   五个界面页面（浮窗 / 查词 / 翻译 / 生词本 / 设置）
config.example.json   配置模板
启动.bat               一键启动（首次自动建环境）
```
