# 暖词 · Windows 取词翻译助手

> 离线优先的 Windows 桌面取词工具：按住 Shift 指向英文单词，浮窗立刻给出音标、考纲标签、简明释义和词形变化；
> 词库用开源的 ECDICT 或你自己的 MDict（`.mdx`）词典，不依赖任何商业词典程序。

## 2.0 有什么不一样

2.0 是一次从头重写，目标是取词体验接近 Mac 上的欧路词典：

- **取词更准**：三级取词——程序支持系统文字接口（Word、记事本、WPF/UWP 程序）时直接拿到准确的词；
  其他地方（浏览器、PDF、图片、游戏）用 **Windows 自带的文字识别**，逐词给出方框，不再按字符宽度去猜；
  系统识别不可用时才退到 RapidOCR。取到的词会核对位置，对不上就换下一级
- **取词更快**：去掉了页面轮询，结果直接推给浮窗；系统识别一次约几十毫秒
- **浮窗按欧路的逻辑排**：词头 → 英/美音标（各自能发音）→ 考纲标签、柯林斯星级、牛津 3000 →
  按词性分行的简明释义 → 词形变化；变形词（went、abandoned）标出原形，点一下就跳过去；
  底部切换各本词典的原版排版
- **看得出取的是哪个词**：屏幕上给取到的词加一层浅色底；浮窗贴在词的正下方，不挡这一行，
  底部放不下自动放到上方；鼠标从词移到浮窗上不会收起
- **划词翻译**：选中一段文字，旁边出现翻译按钮
- **界面全部重做**：统一的浅色 / 深色主题（跟随系统），系统字体，查词窗左侧联想与历史、右侧完整释义
- **启动更轻**：启动时只建取词浮窗，其他窗口用到才建；词典原版排版里的图片、样式、录音按需读取，
  不再整段内嵌，首次显示不卡

## 功能

| 功能 | 怎么用 |
|---|---|
| 鼠标取词 | 默认**按住 Shift 指向单词**即取词，读文章时不会乱弹。设置里可改成按住 Ctrl / Alt，或「停住即取词」 |
| 立即取词 | `Ctrl+Alt+E` 取鼠标下的词（查不到也会告诉你） |
| 查词窗 | `Ctrl+Alt+D`；输入即查、↑↓ 选联想词、拼写纠错（dictionery → dictionary）、词形回溯（happily → happy） |
| 翻译选中内容 | 选中文字后 `Ctrl+Alt+T`，或点选区旁边的翻译按钮；整句翻译 + 句中生词（常用词自动略过） |
| 生词本 | 浮窗 / 查词窗的星标，或 `Ctrl+Alt+B` 收藏鼠标下的词；导出 CSV、Anki |
| 发音 | 英 / 美音分别发音；词典自带录音直接播放；没有录音的例句后面有朗读按钮；离线时用 Windows 自带语音 |
| 原版排版 | 读取词典同目录的 `.mdd`（发音、图片、样式），按词典自己的样式显示；点交叉引用直接跳转 |
| 取词开关 | `Ctrl+Alt+S`，或托盘菜单「鼠标取词」 |
| 退出 | `Ctrl+Alt+Q`，或托盘菜单 |

浮窗里：`Esc` 关闭，`←` `→` 切换词典，点图钉按钮钉住后不会自动收起。

## 系统要求

- Windows 10（2004 及以上）/ Windows 11，使用系统自带的 WebView2（Win11 自带，Win10 一般也已装好）
- 想要最好的英文识别效果：系统里装上英语的「光学字符识别」
  （设置 → 时间和语言 → 语言和区域 → 添加语言 → English (United States)，只勾「基本键入」和「光学字符识别」即可）。
  没装也能用：中文系统自带的识别同样认英文，只是略差一些。托盘「自检」会告诉你当前用的是哪种识别
- 从源码运行需要 Python 3.10+（64 位）

## 快速开始

**方式一：下载打包好的版本（推荐）**　到 [Releases](../../releases) 下载 `WarmWord-windows.zip`，解压后双击 `WarmWord.exe`。

**方式二：从源码运行**　安装 Python 3.10+（勾选 *Add Python to PATH*），双击 `启动.bat`，首次会自动建虚拟环境并安装依赖。

**第一次启动**　托盘出现蓝色「词」字图标即启动完成。还没有词典时会自动打开设置，点「**下载 ECDICT**」
（约 63MB，77 万词条，带音标、考纲标签、柯林斯星级、词形变化），下载完自动启用。

## 词典

- **ECDICT**（[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可）：浮窗的「简明」内容主要来自它，建议放在词典列表第一位。
  GitHub 连不上时可以手动下载 `ecdict.csv`，再在设置里「添加词典文件」选它。第一次加载会花半分钟建索引，之后秒开
- **MDict（`.mdx`）**：和欧路词典、GoldenDict 同一种格式。发音、图片、样式一般在同名的 `.mdd` 里（如 `oaldpe.mdx` + `oaldpe.mdd`，或分卷 `oaldpe.1.mdd`），
  **要和 `.mdx` 放在同一个文件夹**。没有 ECDICT 时，浮窗会尽量从 mdx 释义里提取音标和简明释义

> 本项目不附带任何词典文件（商业词典有版权，请自行合法获取）。

## 整句翻译

几个来源同时请求，按优先级取第一个成功的结果：百度翻译开放平台（选填 APP ID 和密钥，国内推荐）→ 谷歌免费端点 → MyMemory。
连不上的来源 10 分钟内不再等它。

## 数据存放位置

配置、生词本、查词历史、发音缓存、导出文件、日志都在 `%APPDATA%\WarmWord`（设置 → 通用 → 数据文件夹）。
程序目录放一个空的 `portable.txt` 即为便携版（数据跟着程序走）。1.x 的配置会自动迁移。

## 工作原理

```
main.py                     入口（打包版带 --capture-service 时充当取词服务）
warmword/
  app.py                    主程序：串起取词、词典、窗口、热键、托盘
  hover.py                  取词节奏（按住键 / 停住 / 收起浮窗的判断，纯逻辑，有单元测试）
  capture/
    service.py, client.py   取词服务（独立进程，卡住会自动重启）与客户端
    uia.py                  系统文字接口取词（核对方框，Chromium 系不走这里）
    winocr.py               Windows 自带文字识别（逐词方框）
    rapid.py                RapidOCR 兜底
    geometry.py             选词、拆行、浮窗位置（纯函数）
    clipboard.py            模拟复制读选区（读完恢复剪贴板）
  dictionary/
    books.py, engine.py     mdx / ECDICT 读取与合并查询
    card.py                 单词卡片（音标、标签、简明释义、词形、原形）
    morph.py                词形回退、编辑距离
    resources.py            mdd 资源与原版排版改写
  server.py                 本机资源服务（127.0.0.1 + 随机口令）：界面、词典资源、在线发音
  windows.py                窗口管理（浮窗用系统接口控制：不抢焦点、不进任务栏、截图时隐身）
  overlay.py                取词高亮（原生分层窗口，点击穿透）
  api.py                    页面能调用的接口
  config.py, store.py       配置、生词本、历史
  hotkeys.py, tray.py, autostart.py, speech.py, sapi.py, translate.py, wordlist.py
ui/                         theme.css（颜色变量、浅色/深色）、common.js（卡片、原版排版、发音）与六个页面
```

## 开发

```bash
pip install -r requirements.txt pytest
python -m pytest -q tests
```

纯逻辑部分（词典、卡片、取词几何与节奏、配置、资源服务）在任何系统上都能测；`tests/test_windows.py` 只在 Windows 上跑，
会真的用系统文字识别认一张渲染出来的图片。GitHub Actions 在 Windows 上跑全部测试、用 PyInstaller 打包并做冒烟测试；
推送 `v*` 标签时自动发布 Release。
